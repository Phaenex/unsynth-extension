Suggestions for your taste

Unsynth builds a private, on-device picture of what you actually watch — the words in the titles and the channels you return to — and scores the watch-page suggestion rail against it. Recent viewing counts for more than old viewing, so the profile follows your interests as they change instead of averaging everything you have ever clicked. Nothing leaves your machine and nothing is sent to any server.

Detection sensitivity

Signals are weighted, not all-or-nothing: a creator's own “altered or synthetic content” disclosure scores 100, phrasing like “AI voiceover” scores 70, a named tool (Midjourney, ElevenLabs) 40, and a passing mention (“ChatGPT”, “Sora”) 20. Wording that indicates a human talking about AI — “review”, “how I use”, “tutorial” — subtracts. A video is only treated as AI once the total reaches this threshold.

Lower catches more but flags more ordinary videos; higher only acts on strong evidence. 45 is the default. In “Label as AI” mode the badge shows the score, so you can see how certain each call is.

Sync across devices

Optional. Sends your watched-video IDs, how far you got (percent), and the date you watched each one to the Unsynth sync server (unsynth.vercel.app). Never sends titles or channels. To know it is you, each sync also sends your Google sign-in token; the server only uses it to ask Google which channel is yours, does not store it, and files your data under a one-way hash of that channel. Requires the Google OAuth setup on the Account tab on each device you want synced.

How to get your Takeout file

Go to takeout.google.com → Deselect all → tick YouTube and YouTube Music → its “All YouTube data included” → keep only history (format HTML or JSON) → export. Unzip and import the watch-history.html (or .json) file above.

Troubleshooting live tracking

After reloading the extension on your browser’s extensions page (chrome://extensions), you must reload each open YouTube tab (or open a fresh one) before tracking resumes. Watch past 75%, then check the Live tracker card above. In DevTools console: 

chrome.storage.local.get('watchStats', d => {
  const w = d.watchStats || {};
  const today = new Date().toISOString().slice(0, 10);
  console.log('plays:', w.total, '| distinct:', w.uniqueVideos,
    '| today:', (w.byDate||{})[today], '| live:', w.live);
});

    Manual update steps
    1. Click Fetch latest ZIP below, or download it from unsynth.vercel.app.
    2. Unzip it over your existing Unsynth folder, the one that holds manifest.json. Keep the same folder so your settings stay.
    3. Click Reload Unsynth, then Reload YouTube tabs.

    On Mac, Fetch latest ZIP downloads the deployed release. Unzip it over the existing Unsynth folder, keeping the same folder path, then reload Unsynth. If this is a git clone, npm run update remains the simplest option.
