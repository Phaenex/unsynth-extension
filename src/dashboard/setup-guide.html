Privacy / Data Flow

There is no Unsynth analytics server, and nothing is collected by default. The only exceptions are features you turn on yourself — each one is opt-in and sends a minimal, disclosed payload, never your full history.

  • Local Storage: Watch history, watch progress, stats, subscription groups, playlist folders, and settings all live in chrome.storage.local on your own device by default. Watch history and progress are uploaded only if you explicitly enable Sync across devices (Watched tab) — otherwise nothing here ever leaves your device.
  • Secrets: OAuth client secrets, AI provider API keys, and GitHub access tokens stay only on your machine.
  • External Calls: Unsynth only talks to the services you opt into, or to public community APIs: www.youtube.com, music.youtube.com, suggestqueries.google.com (Creator Studio autocomplete), returnyoutubedislikeapi.com / sponsor.ajay.app / dearrow-thumb.ajay.app (community modules, can be disabled), raw.githubusercontent.com (24h AiSList community blocklist sync), unsynth.vercel.app / api.github.com (update checks), oauth2.googleapis.com / www.googleapis.com (OAuth, opt-in), openrouter.ai / api.openai.com / api.anthropic.com (AI APIs, opt-in), playlist-forge.vercel.app (Playlist Forge sync, opt-in), unsynth.vercel.app/api/sync/* (Watch History Sync — watched-video IDs and progress percentages only, opt-in).

1. Install the extension

Unsynth is sideloaded — not from the Chrome Web Store.

  1. Get the folder (git clone, zip, or .crx).
  2. Open chrome://extensions (or Edge/Brave equivalent).
  3. Enable Developer mode → Load unpacked → select the folder with manifest.json.

Requires Chromium 120+. Firefox is not supported.

2. Reload YouTube tabs

  1. Open the Unsynth dashboard (toolbar icon → ⚙).
  2. Click Reload YouTube tabs.

3. Google OAuth (YouTube API)

Optional — skip if you only need free features. For subscription import, playlist tools, and Forge “Create on YouTube”. Each user creates their own OAuth client — never share someone else’s secret. Free at personal scale.

Illustrative — a simplified recreation of the Google Cloud Console, not a live screenshot. Your actual screen will look like Google's current console design.

3.1 Google Cloud project

  1. Google Cloud Console → New project.
  2. APIs & Services → Library → enable YouTube Data API v3.
  3. OAuth consent screen → External → fill required fields → add yourself as a Test user if the app is in Testing.

Illustrative — same as above, not a live screenshot of the real credentials page.

3.2 OAuth client

  1. Credentials → Create credentials → OAuth client ID.
  2. Type: Web application.
  3. Authorized redirect URI: copy from dashboard → Account tab — must match exactly.
  4. Copy Client ID and Client secret.

3.3 Connect in Unsynth

  1. Dashboard → Account → paste credentials → Save credentials.
  2. Click Connect YouTube (read + write).

Optional — skip unless you want transcript Q&A or fact-check. Needed for: watch-page AI assistant (transcript summaries, Q&A) and AI fact-check. Not needed for: AI content filter or Forge Search discover. Pay-per-use — typical small models ~$0.15–0.50 per million tokens.

  2. Pick OpenRouter, OpenAI, or Anthropic and paste your key.

5. Import watch history (optional)

Google Takeout or PocketTube/Watchmarker JSON via the Watched tab. Free. See youtube-history-to-import/IMPORT-FORMATS.txt in the repo.

Video stats & compare

After reload, Unsynth shows likes, dislikes, ratio, and views on search, home, and subscription feeds (under each title) and on watch pages — powered by Return YouTube Dislike. On watch pages you also get counts on the like/dislike buttons, a stats strip with Compare, and the sidebar ✦ Stats overlay. Optional — configure under Modules → Video stats (toggle feed tiles there).

6. Staying updated

After git pull: reload the extension on chrome://extensions, then Reload YouTube tabs. Free.

Public repo: Check for updates works without a GitHub token. Private repo: add your own PAT with repo scope on Account → Updates.

Recommended profile (optional)

If the author shares an unsynth-profile.json, import it on the Modules tab → Import settings profile. You still add your own OAuth and AI keys afterward.

What never to share

  • OAuth Client Secret, AI keys, GitHub PAT
  • Google OAuth tokens (auto-managed)
  • tools/extension-key.pem (local packing key)

Settings profile export includes preferences only — no secrets.
